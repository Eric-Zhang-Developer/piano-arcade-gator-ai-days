# Unselected brand study

Read [Product philosophy](../../../PRODUCT_PHILOSOPHY.md) first. These are
review options, not approved product names or a selected replacement identity.
The canonical `/learn` experience remains the incumbent described in DESIGN.md.

Open `/learn/brand-preview` on desktop. A neutral review strip chooses the
option or explicitly replays it from a fresh home; this strip is outside the
student experience. Each direction offers one prepared Start/real Resume,
a gator journey to the actual phrase-endings skill, arrival, and the existing
interactive TheoryWorkspace. Back returns to that option's map. Preview
sessions are isolated from the canonical learning session and from other
options; replay deliberately resets only the study session.

| Direction | Visual character | Composition | Motion character |
|---|---|---|---|
| Practice Room | Warm paper, wood-toned rules, Georgia headings and Helvetica Neue reading | A trusted teacher beside a broad wall map; the lesson reads like an open practice book | Measured low-arc glide, slight lean, then a page-like horizontal reveal |
| Field Notes | Practical cream journal, evergreen action, Trebuchet MS reading/headings, small incumbent Saira wordmark | A left journal margin gives the guide its own space beside the real map; the lesson remains clear and usable | Modest buoyant glide, 8-degree lean, then a compact circular opening |
| After Hours | Warm dark green, soft brass, Baskerville headings and Helvetica Neue reading | A centered quiet wordmark, generous spacing and a calm map; the lesson shares the same evening surfaces | Slower curved drift, nearly upright guide, then a gentle opacity reveal |

These use installed browser fonts, the existing gator SVG, real subject/learner
fixtures, the exact authored root relationships and the existing projection/
caption functions. World geography and dense meaningful fans remain intact.
Parents/leaves share the three mastery presentations; no legend, due marker,
mode choice or free roaming is added. Surface contrast is tuned for each world.
No generated media or new runtime dependency is required.

The copy offers a manageable actual task: hear two phrases and compare their
endings. It does not invent recent mistakes, measured mastery, model decisions
or a guaranteed outcome. The gator travels with the learner, then hands off into
a compact stationary tutor beside the activity heading. The real question
continues that guide voice; internal mode labels are absent in the study.
The canonical activity keeps its existing heading/subtitle behavior.

Source: `web/src/learn/frontend/brand-preview/BrandPreview.tsx`,
`directions.ts` and `brand-preview.module.css`. The route has no publication or
brand-selection authority. Field Notes adapts the parallel source-fidelity,
copy, color, layout and motion handoff; it is not a second application.

## Review evidence and limits

The bounded desktop batch covers all three home/activity views at 1440x900 and
1280x800, actual browser-frozen flight poses with native timing restored, normal
Start/Resume/double-click behavior, isolated replay and retained real answer,
history and selected Reference. One correction batch addresses guide/graph
collision, continuous activity accompaniment/internal mode copy, and hidden
incumbent chrome remaining in the focus surface. Confirmation is limited to
those affected cases.

Native keyboard activation, actual reduced-motion execution, audio output,
offline interruption and full activity completion are not established by this
study's browser evidence. Native controls, existing cleanup and reduced-motion
code paths remain; this is an interactive comparison, not production acceptance.
No mobile study or permanent DESIGN token change is included.
