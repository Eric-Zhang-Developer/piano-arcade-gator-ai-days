## What shipped
A `browser` CI job runs the headless checks on GitHub over 8 shards: `web/e2e/verify.mjs` plus the checks nearest a PR's changes, or every check when shared code changes and on main. One rerun per failure (`flaky`); checks already red on main run as `known red #N` and don't gate. `verify.mjs` also fails on /sim errors, and locally `verify.py` runs one headless check at a time per machine through `verify.lock`.
