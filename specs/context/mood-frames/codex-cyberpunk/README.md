## The brief
"A machine that hears every note, and a reason to play one more time." An instrument-grade HUD (F1 telemetry,
Valorant): mostly empty dark space, 1px hairlines, corner brackets, small monospace caps for data, big condensed
numerals for score and combo, color saved for moments. No synthwave sun, no grid floor, no neon soup.
