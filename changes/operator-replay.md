## What shipped
`/attract`, attract mode for the operator board: a three.js synthwave stage (neon grid, low sun, slow orbit) with one pillar per feature spec, layered by `depends_on` with floor lines. Pillars rise out of the grid with a flash and a ring of light, one merged PR per note of Twinkle on the chart's own rhythm, while each step's note plays: on the DGX ("Portable Grand") over Web MIDI, or as a laptop tone. HTML counters (features done of planned, PRs merged, agents at work) end on the board's numbers. Also: a 3-line ticker, chapters computed from the data (first PR, milestones built, peak PRs open), Space and a scrubber, a wall-clock toggle, and clicking a pillar shows its spec, PR and done-note links. Below the stage is an SVG crew timeline, one row per worker with stacked sub-rows, an open-PR strip, tooltips and a table version. Without WebGL the graph is a flat list that still plays. Live from `/api/operator`, or `?snapshot`. Since #1286's follow-up: `/attract?film=1`, the cut for the video, plays the snapshot's whole build in about 17 s, silent, with only the stage, one title line and three counters climbing to the real numbers (features done, PRs merged, agents so far), then holds a hero frame of the PR and feature counts in the moment face.
