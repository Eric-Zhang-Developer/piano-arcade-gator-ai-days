## What shipped
`/operator`, the arcade's operator menu in synthwave bookkeeping: a coin-counter strip, then **Needs a person** (non-draft plan/contract PRs, needs-human and blocked issues, drafts stale at 45 min, red main CI, STOP), **Crew** (workers from `Worker:` lines, CI per PR, heartbeats in LIVE only) and **Bookkeeping** (done of planned per milestone with each feature's state, merges by type, median open→merge, 3 longest builds, first PR). Keys 1–3 jump. LIVE polls `/api/operator` every 15 s; the server collects at most once a minute with 4 `gh` calls. "Freeze snapshot" writes `web/public/operator/snapshot.json`, minus heartbeats; `?snapshot` and production builds read only that file. If `gh` fails, the board is built from repo files with a banner saying what's unknown.
## Where it lives
`web/src/operator/` (`board.ts` model and readers, `collect.ts` collector and cache, tests, `verify-operator.mjs`), `web/src/app/operator/` (page, layout, error boundary, CSS), `web/src/app/api/operator/` (live and snapshot routes, 404 in production).
